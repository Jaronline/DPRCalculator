# [DPR Calculator](https://dprcalculator.jaronline.dev/)

Calculator for damage per round in D&D 5e

## Features

* Add multiple rounds
* Last round simulation
* Duplicate rounds and attacks
* Advantage, disadvantage and elven accuracy calculation
* Halfling lucky calculation
